Integrated Project Sem 2.2

Website design, Firebase integration, and implementation support for the project platform.

What I did

I was the lead designer for the website and the lead developer for the Google Firebase functionality. My work focused on building a clear interface, connecting the front-end to the backend, and making sure the project data could be stored and retrieved reliably.

  • Designed the website layout and user interface in Figma.
  • Built the front-end and back-end components with HTML, CSS, and JavaScript.
  • Implemented Google Firebase Web and Unity integration for authentication and real-time data storage.
  • Worked with teammates to make sure the website fit smoothly into the overall project.
  • Used Firebase's NoSQL database to support core game mechanics, including a dynamic unlocking system that keeps player progress synchronized across sessions.
